# Screenshots

No screenshots are included in this archive: the environment used to build the
project had no web browser, so the interface could not be captured.

To add your own after running `streamlit run app.py`:

1. Take screenshots of the main page, a Kannada result and a Hindi result.
2. Save them here as `home.png`, `kannada.png` and `hindi.png`.
3. Add them to the README with `![Home](screenshots/home.png)`.
